# Mark’s Bahala Na!

**The barangay survival game. A game by Mark.**

You just moved into Barangay Bagong Pag-asa with ₱1,000, a borrowed electric fan and big dreams. Five rival households want the same thing you do: the Fiesta Videoke Grand Champion crown.

Build sari-sari stores and Piso WiFi, hire tambays, spread chismis, raid your neighbors, call your Lodi, and sing your way to seven perfect 100s before anyone else does.

## Play

- **In a browser:** turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). The game is the single file `index.html`.
- **On Android:** every push to `main` builds an APK. Open the **Actions** tab, pick the latest **Build APK** run, and download **Bahala-Na-APK** at the bottom of the page.

## Files

| File | What it is |
| --- | --- |
| `index.html` | The whole game: HTML, CSS and JavaScript in one file |
| `assets/icon-only.png` | App icon (1024 × 1024). Replace it to change the icon |
| `capacitor.config.json` | App name and package ID for the Android build |
| `package.json` | Capacitor versions used by the build |
| `.github/workflows/build-apk.yml` | GitHub Actions workflow that builds the APK |
